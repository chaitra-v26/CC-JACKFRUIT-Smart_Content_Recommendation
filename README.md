# Smart Content Recommendation

This project implements a **Smart Content Recommendation System** that intelligently suggests content based on user preferences and behavior.

## Tools and Frameworks Used

- **Python** – Core programming language for implementation  
- **Pandas** – For data manipulation and preprocessing  
- **NumPy** – For numerical operations  
- **Scikit-learn** – For building and evaluating machine learning models  
- **Flask** – To develop the web-based interface and REST API  
- **MongoDB Atlas** – Cloud-based NoSQL database for storing user data and recommendations  
- **Jupyter Notebook** – For prototyping and experimentation  
- **HTML/CSS/JavaScript** – For building the frontend  
- **Bootstrap** – For responsive UI design  
- **Git** – Version control  
- **GitHub** – Code hosting and collaboration platform
